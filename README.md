# CORO Crafted Collective

A Next.js concept site for CORO as a digital material experience centre.

## Run locally

1. Install Node.js 20.9 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Content note

The current photography is editorial placeholder imagery used to establish visual direction. Replace the remote image URLs in `app/page.tsx` with approved CORO photography before launch. Appointment availability, operating hours, address and technical product information are deliberately not claimed in the prototype.
